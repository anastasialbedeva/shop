# 🌿 Зелёная полка — интернет-магазин растений

Лабораторная работа: интернет-магазин, в котором можно просматривать каталог товаров, добавлять их в корзину и оформлять заказ.

**Демо:** https://anastasialbedeva.github.io/shop/

## Стек

Только чистые технологии, без фреймворков:

- HTML5 (семантическая разметка: `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`, `dialog`)
- CSS3 (Flexbox, Grid, медиазапросы)
- JavaScript (ES6+), `localStorage`

## Возможности

- Каталог из 8 карточек товаров (данные в `js/data.js`, карточки создаются через `createElement`) с названием, ценой и кнопкой «Добавить в корзину»
- Корзина: добавление, удаление, изменение количества (кнопки +/− и ручной ввод)
- Автоматический пересчёт суммы по позициям и итоговой суммы
- Сохранение корзины в `localStorage` — она не пропадает после обновления страницы
- Модальное окно оформления заказа по кнопке «Оформить заказ»
- Форма: имя, фамилия, адрес доставки, телефон, кнопка «Создать заказ» с валидацией полей
- Сообщение «Заказ создан!» после успешного оформления
- Адаптивная вёрстка: ноутбук, планшет, смартфон

## Адаптивность

| Ширина экрана | Раскладка |
|---|---|
| > 1024px | каталог + корзина сбоку (закреплена) |
| 769–1024px | каталог, корзина под ним |
| 481–768px | навигация под логотипом, одна колонка в «О нас» |
| ≤ 480px | карточки в одну колонку, горизонтальные |

## Структура

```
├── index.html          — разметка страницы
├── README.md
├── css/
│   └── style.css       — стили и медиазапросы
├── js/
```

## Запуск

Открыть `index.html` в браузере — сборка не нужна.
